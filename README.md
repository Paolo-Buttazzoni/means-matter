# The Means Matter Project

This repository contains data, analysis scripts and pre-registrations for our manuscript titled _"Body envelope invasion, not moral reasoning, drives opposition to biotechnological enhancement"_.

Explore the materials to learn more about our research into how the _means_ by which human enhancement is achieved influences moral attitudes.

### Index

- The [Study 1. Do means matter morally?](/study1/) folder contains study materials, data and scripts, for the first study in which we sought to uncover any general preference for either conventional or biotechnological methods of human enhancement.

- [Study 2a. Justifications for moral attitudes.](/study2a/)
- [Study 2b. Correlates of moral attitudes.](/study2b/)
